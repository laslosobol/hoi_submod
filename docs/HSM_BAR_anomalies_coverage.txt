Evidence, knowledge, access
--------------------------
Global HSM_BAR_case_* facts record existence, creation, transformations and
manifestations. Native hooks never mark BAR knowledge. BAR _known/_investigated
flags result from surveys/archives/forensics; Crown knowledge is on each origin
record and the BAR overview. Country _surveyed records the visited jurisdiction,
not ownership or permanent access. A case can remain known after access is lost.
There is no cached global accessible flag. Current controller, physical evidence,
native custody mode and project gates are tested again on operation completion.
Expired completions set HSM_BAR_case_last_operation_expired, clear success, and
grant neither physical items, reward, incident nor new investigation credit.

Foreign decision expeditions provide a playable route without espionage DLC;
the separate native operations owner calls the same public predicates/effects.
Recon requires a currently located Crown/relic, confirmed pre-return bones, or
records of an actual transformation/return/execution/final rest. Bare control of
Yale, Magehold or the Crystal City and historical existence flags are not leads.
Survey and archive effects grant only the cases justified by that evidence.
A later native discovery can reopen recon in an already surveyed country.
Location follows the current controller; a former custodian loses eligibility.
Native wrappers and fallback target_trigger/visible/available use the same public
target predicates. Completion rechecks those predicates before granting results.

Relic/remains theft retains the native stole_gift_opinion penalty from current
custodian to BAR, a custodian notification, and a 20 PP handling cost. The report
identifies transport intermediaries, never the hidden network. Barrad's cabinet
does not know the network controls it through false fronts. Local precautions
protect residents under civilian cover, without public hearings or persecution.
No anomaly effect reads or modifies HSM_BAR_public_trust, which belongs to the
Collegium. No anomaly effect adds retired HSM_BAR_repressive_methods or the
SMILE-specific HSM_BAR_smile_compromised flag. The Service has no numeric secrecy
meter. Case progression uses concrete evidence, custody and outcome flags, with
explicit costs and consequences; it must not reuse Collegium public trust.

shorthand, with negative controls demonstrating each rejection.

different numeric trigger. The installed documentation lists only =, <, >
shorthand for check_variable; inclusive bounds use explicit var/value/compare.

compare = greater_than_or_equals }. The log directly proves the <= rejection;
replacing >= is also required by the documented form, but no separate >= engine
failure was observed in this log. This is not a claim about every numeric trigger.

both unsupported shorthand forms have negative syntax tests. The original main
pass corrected the HSM_BAR_core.txt SMILE threshold to this explicit syntax.
That threshold was subsequently removed with the numeric secrecy mechanic;
the syntax tests remain applicable to surviving capacity checks.
